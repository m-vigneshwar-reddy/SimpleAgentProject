📧 Connect Your Real Email
Fill in the .env file in the project folder. These steps take about 3 minutes.
1
Open the .env file in VS Code
It is already in your project folder. Click it in the VS Code file explorer on the left.
2
Set your email address
EMAIL_ADDRESS=yourname@gmail.com
3
Generate an App Password (not your normal password)
Gmail: Go to myaccount.google.com/apppasswords
Select Mail + Windows Computer → Generate → copy the 16-letter password

Outlook: Go to account.microsoft.com/security
→ Advanced security options → App passwords → Create a new app password
4
Paste it into .env
EMAIL_APP_PASSWORD=abcd efgh ijkl mnop
EMAIL_PROVIDER=gmail
5
Save .env and restart the server
Press Ctrl+C in the terminal, then type: npm start
